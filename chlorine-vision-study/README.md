# Chlorine Vision Study

This repository contains the training pipeline and mobile app for a smartphone-based chlorine concentration detector. The app analyzes a photo of a pink DPD-prepared water sample and returns chlorine concentration in `mg/L`.

## What Is In This Repo

- `mobile/`  
  Expo React Native app for capturing or uploading a sample photo, running on-device analysis, and viewing scan history.

- `training/`  
  Training, evaluation, feature extraction, augmentation, model export, and saved model artifacts.

- `main.py`  
  FastAPI API for Python-side model serving and debugging.

## Current Model Status

- Full saved pipeline model: `ElasticNet Regression`
- Mobile app model: `Mobile Lasso Regression`
- Reason for selection: both were chosen as practical low-overfitting models while preserving strong predictive performance

Saved metrics are in:

- `training/saved_artifacts/model_metadata.json`
- `training/saved_artifacts/mobile_model_metadata.json`
- `training/saved_artifacts/candidate_results.json`
- `training/saved_artifacts/poster_metrics.json`

## Run The Mobile App

From the repository root:

```bash
cd mobile
npm install
npx expo start -c
```

Then open Expo Go on your phone or launch the iOS simulator.

Note: the mobile app performs inference on-device and does not require the Python API for normal use.

## Run The Python API

If you want to test the saved Python model separately for debugging:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Retrain The Models

1. Convert a folder-based image dataset into JSON:

```bash
python convert_images_to_json.py /path/to/chlorine_data training/new_dataset.json
```

2. Run the full training pipeline:

```bash
python -m training.run_full_pipeline
```

3. Export the mobile app model:

```bash
python -m training.train_mobile_deployable_model
```

4. Check train-vs-holdout gaps:

```bash
python -m training.check_overfitting
```

5. Export a compact poster/presentation metrics summary:

```bash
python -m training.export_poster_metrics
```

## Training Pipeline Summary

The current training workflow:

1. splits original phone photos before augmentation
2. augments only the training subset
3. crops to the test-tube / pink-liquid region
4. extracts color and texture features
5. compares multiple regression models
6. saves the least-overfit practical model artifacts

## Important Files

- `training/new_dataset.json` is kept as the main dataset input for retraining.
- `training/saved_artifacts/` is kept because the app and API depend on those exported models.
- `HANDOFF.md` gives the next intern a quick orientation to the repo.
- `training/augmented_image_data.json`, `training/features_data.csv`, and `training/phone_holdout_dataset.json` are generated by the training pipeline and can be safely regenerated.

## Repo Notes

- `training/run_full_pipeline.py` is the main full training script.
- `training/train_mobile_deployable_model.py` exports the on-device mobile model.
- `training/train_models.py` is an older exploratory script and is not the main production path.
- `poster_assets/` holds the poster chart code and generated figures.
